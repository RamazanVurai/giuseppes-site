# Como trocar as fotos do site

Este guia é para quem administra o site. Os textos que os visitantes veem continuam em português brasileiro; os arquivos HTML, CSS e JavaScript e seus nomes permanecem em inglês.

Para editar os textos de qualquer uma das cinco páginas, consulte [EDITAR-TEXTOS.md](EDITAR-TEXTOS.md).

## Passo a passo

1. Abra a pasta `assets` dentro da pasta do site.
2. Encontre a foto usando a lista abaixo.
3. Faça uma cópia de segurança da foto antiga.
4. Coloque a foto nova no mesmo lugar, com exatamente o mesmo nome e a mesma extensão.
5. Atualize a página no navegador. Se ainda aparecer a foto antiga, atualize sem usar o cache com `Ctrl + Shift + R`.

Não é necessário editar HTML, CSS ou JavaScript. Não apague nem renomeie o arquivo.
