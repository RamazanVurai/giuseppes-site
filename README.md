# Giuseppes Hair Studio — recriação editável

Site responsivo feito com HTML, CSS e JavaScript. O conteúdo visível está em português brasileiro; nomes de classes, arquivos e variáveis estão em inglês.

## Personalização

Abra `content.js` para alterar:

- `whatsappNumber`: telefone com código do país e DDD, somente números.
- `instagramUrl`: endereço do Instagram do salão.
- `fontHeading` e `fontBody`: famílias tipográficas.
- `images`: endereços das imagens de capa, editorial e galeria.

As páginas Início, Serviços, Portfólio, Sobre Nós e Contato foram reproduzidas como arquivos HTML separados. Os textos de todas as cinco páginas podem ser alterados diretamente nos arquivos HTML. Consulte [EDITAR-TEXTOS.md](EDITAR-TEXTOS.md) para ver como encontrar e trocar textos. As fotos das páginas Início, Serviços, Portfólio e Sobre Nós ficam em arquivos locais e podem ser substituídas mantendo o mesmo nome. Consulte [TROCAR-FOTOS.md](TROCAR-FOTOS.md) para ver o passo a passo e a lista de arquivos. Contato fica fora apenas do procedimento de troca de fotos.

O formulário de contato abre uma mensagem pré-preenchida no WhatsApp, sem enviar nada até a pessoa confirmar o envio no próprio WhatsApp. Para publicar, envie todos os arquivos desta pasta para uma hospedagem de site estático, mantendo-os juntos.
